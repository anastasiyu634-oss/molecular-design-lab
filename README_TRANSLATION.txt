Molecular Design Lab v4.10.1 — экспериментальная защита от ошибок Chrome Translate
================================================================================

Проблема:
После перевода страницы в Chrome некоторые текстовые узлы заменяются браузером,
и React (который использует Streamlit) может выдавать NotFoundError: removeChild.
Эта ошибка зарегистрирована в upstream Streamlit: https://github.com/streamlit/streamlit/issues/7745

Что изменено:
- В начале app.py подключён translation_support.install_browser_translation_guard().
- Он указывает исходный язык страницы ru, не запрещая перевод.
- Через st.html(..., unsafe_allow_javascript=True) пробует установить клиентский
  open-source guard translation-resilience@0.3.0. Он восстанавливает изменённые
  браузерным переводчиком DOM-узлы перед операциями React.
- Библиотека загружается из cdn.jsdelivr.net, поэтому нужен интернет и разрешение
  на загрузку скриптов. Лицензия сторонней библиотеки — MIT.
- Модули расчётов, результаты Vina и Python зависимости химии не изменены.

Известные ограничения:
- Streamlit должен быть >=1.52 (наличие st.html с unsafe_allow_javascript).
- Совместимость с переводом Chrome в реальном браузере не гарантирована;
  пакет — стороннее экспериментальное смягчение, а не официальный фикс Streamlit.
- Нельзя считать CDN-скрипт полностью проверенным для публичного production:
  требуется security-review или вендоринг проверенного кода и его дальнейшая поддержка.
- Если Chrome не может загрузить скрипт, сайт продолжит работу, но без защиты.
- Встроенные 3D iframe живут в отдельном документе и этой защитой не охвачены.

Как обновить установленную v4.10:
1. Остановите сайт в VS Code (Ctrl+C).
2. Замените app.py, requirements-core.txt и requirements.txt и добавьте translation_support.py.
3. В окружении проекта выполните:
   .\.venv\Scripts\python.exe -m pip install -U "streamlit>=1.52,<2"
4. Запустите сайт:
   .\.venv\Scripts\python.exe -m streamlit run app.py
5. Откройте обычный Chrome, включите перевод страницы, переключайте этапы,
   формы, раскрывающиеся блоки и 3D; проверьте, исчез ли removeChild.
6. Если ошибка остается, откройте F12 → Console и проверьте,
   нет ли сообщения '[Molecular Design Lab] Translation guard unavailable'.

Если сайт нужно сделать по-настоящему многоязычным для пользователей,
следующий шаг — перевести все интерфейсные строки с помощью словарей i18n,
а не полагаться исключительно на автоматический перевод браузера.
