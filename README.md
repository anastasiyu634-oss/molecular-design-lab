# Molecular Design Lab — дизайн 1 + 3

Новая версия нашего сайта на Python и Streamlit: **спокойная «лаборатория» + пошаговое исследование**.

## Что работает

- **01 · Структуры:** загрузка до 10 структур из RCSB PDB по идентификаторам, поиск крупных неводных компонентов и аминокислотных остатков на расстоянии ≤ 4 Å. Таблицы и скачивание CSV.
- **02 · Анализ:** выбор предполагаемого лиганда для каждой структуры, таблица и предварительное сравнение близких аминокислотных остатков по названию и номеру. Важно: белки здесь **ещё не выровнены**, типы связей не определяются, это **не фармакофор**.
- **03 · Дизайн** и **04 · Докинг:** пока страницы с описанием дальнейшей разработки. Они не выполняют вычисления и не показывают фиктивные результаты.

## Запуск на Windows в VS Code

1. Распакуйте архив в **новую папку**, не поверх старого сайта.
2. В VS Code выберите **Файл → Открыть папку** и откройте папку `molecular_design_lab_v2` (там, где находится `app.py`).
3. Откройте **Терминал → Создать терминал**.
4. Выполните:

   ```powershell
   py -m pip install -r requirements.txt
   py -m streamlit run app.py
   ```

   Если команда `py` не работает, замените её на `python`.
5. Сайт откроется по адресу `http://localhost:8501` (или адресу из терминала).

Остановка сайта: `Ctrl+C` в терминале.

Если приложение уже запущено на порту 8501, закройте его в терминале или запустите новый сайт так:

```powershell
py -m streamlit run app.py --server.port 8502
```

В таком случае адрес будет `http://localhost:8502`.

## Что находится в проекте

- `app.py` — навигация, шаги исследования и логика интерфейса.
- `analysis.py` — загрузка PDB и первичный расчёт близких остатков.
- `ui_styles.py` — внешний вид. **Позже поменять дизайн можно отдельно от расчётов**.
- `.streamlit/config.toml` — светлая тема и спокойная палитра.
- `requirements.txt` — используемые библиотеки.

## Первое тестирование

В шаге 01 введите `1A9U, 1OUY, 1W7H`, нажмите «Загрузить структуры» и затем «Перейти к сравнению». Для скачивания файлов нужен интернет. Никакие данные не публикуются в интернете — сервер работает на вашем компьютере.

## Научные ограничения

Обнаруженные неводные компоненты могут не быть ингибиторами. Дистанция ≤ 4 Å — всего лишь критерий геометрической близости, а не автоматически водородная связь. Совпадение остатков по номеру — ориентир для проверки, но не полноценное выравнивание белков. До de novo дизайна и докинга ещё несколько этапов разработки.
